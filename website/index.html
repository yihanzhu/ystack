Two parts

The kit and the layer pass.

Part 1

The kit

My working preferences, how I split work between models, and my development skills. Claude Code and Codex load it from this repo. It changes only through pull requests. A work computer installs only ystack.

Part 2

The layer pass

Before agents work in a codebase, ystack goes over it one layer at a time. Each layer has one question. The pass works by hand for now.

Whose kit It is my own kit. It holds nothing about my life and nothing from an employer.

The five layers

One question for each layer.

  1. 1
    Layer 1

    Design

    Does the design take wrong choices away, so an agent cannot make them?

  2. 2
    Layer 2

    Checks

    Do lints, types, tests and CI run on every change, and can they stop one?

  3. 3
    Layer 3

    Verification

    Can someone verify what the code does when it runs, with runtime checks or evals?

  4. 4
    Layer 4

    Written rules

    Are the rules for agents written next to the code they are about?

  5. 5
    Layer 5

    A person

    Which changes must a person still look at?

Rules

How the layers decide.

01

The highest layer takes the fix

Each layer down costs more. So a fix goes into the highest layer that can hold it.

02

The layers decide merges

A kind of change may merge without me only after every layer in that codebase has been checked and raised to the standard. A merged check decides the kind of a change, never the change's own code. An unknown kind comes to me. Until then, I merge every PR.

03

Requests come to me last

A request reaches me only when no check and no written rule can answer it. That includes requests for more test runs or more permissions.

04

Checks decide, I answer

Checks can take over deciding. Answering for what goes in stays with me.

Where it stands

By hand first, on two codebases.

My own site has had all five layers. The same pass, with the same kit, still has to work on a second codebase. Automation comes only after it has worked by hand on both.

From June to November 2026, ystack was an autonomous coding team. That work has stopped. The tag archive/run-anywhere keeps it.
